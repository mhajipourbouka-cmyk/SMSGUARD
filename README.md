# پیامک‌گیر (SmsGuard)

برنامه‌ی اندروید برای بی‌صدا کردن پیامک‌های تبلیغاتی، با قوانین قابل ویرایش.

## امکانات
- **فیلتر سرشماره:** ۱۰۰۰، ۲۰۰۰، ۳۰۰۰، ۵۰۰۰، ۹۰۰۰ (قابل ویرایش). شماره‌ی موبایل معمولی (۰۹...) هیچ‌وقت با این قانون بلاک نمیشه.
- **فیلتر کلمه:** «لغو۱۱»، «تخفیف»، «جشنواره» و... (قابل ویرایش). فاصله، نیم‌فاصله، ی/ي، ک/ك و عدد فارسی/انگلیسی فرقی نمی‌کنه.
- **لیست سفید:** شماره‌ها، کلمه‌ها (پیش‌فرض: رمز، کد تایید، برداشت، واریز، ...) و مخاطبین گوشی.
- **آرشیو و آمار:** نسخه‌ای از هر پیام بلاک‌شده با تاریخ شمسی و دلیل بلاک، آمار امروز/۷ روز/کل و پرتکرارترین فرستنده‌ها. با یه لمس فرستنده به لیست سفید میره.
- **تست قانون:** شماره و متن رو وارد کن و ببین بلاک میشه یا نه.

## محدودیت مهم
اندروید فقط به برنامه‌ی پیش‌فرض پیامک اجازه میده پیامک رو پاک یا جلوی ذخیره‌ش رو بگیره.
پیامک‌گیر **اعلان** پیامک تبلیغاتی رو حذف می‌کنه (بدون صدا، بنر و عدد روی آیکون) و یه نسخه توی آرشیو خودش نگه می‌داره، ولی خود پیام توی برنامه‌ی پیامک گوشی می‌مونه.

## ساخت APK

### روش ۱: GitHub (بدون نصب هیچ چیز)
1. یه ریپوی جدید (می‌تونه Private باشه) توی github.com بساز.
2. همه‌ی فایل‌های این پوشه رو آپلود کن (Add file ← Upload files). پوشه‌ی `.github` هم باید آپلود بشه.
3. تب **Actions** ← اجرای «Build APK» رو باز کن، صبر کن سبز بشه (حدود ۵ دقیقه).
4. پایین صفحه از بخش **Artifacts** فایل `SmsGuard-apk` رو دانلود کن؛ داخلش `app-debug.apk` هست.

### روش ۲: Android Studio
پوشه رو با Android Studio باز کن (Open)، صبر کن Sync تموم بشه، بعد Build ← Build APK(s).

## نصب و راه‌اندازی روی گوشی
1. APK رو نصب کن (اجازه‌ی «نصب از منابع ناشناس» رو بده).
2. برنامه رو باز کن، تب «وضعیت»:
   - **دسترسی اعلان** رو فعال کن. اگه گزینه خاکستری بود: تنظیمات ← برنامه‌ها ← پیامک‌گیر ← منوی ⋮ ← Allow restricted settings، بعد دوباره.
   - اجازه‌ی **دریافت پیامک** و **مخاطبین** رو بده.
3. روی گوشی‌های شیائومی/هواوی/سامسونگ، محدودیت باتری پیامک‌گیر رو بردار (Battery ← No restrictions) که سیستم خاموشش نکنه.
4. از بخش «تست قانون‌ها» یه پیامک نمونه رو امتحان کن.

## حریم خصوصی
هیچ دسترسی اینترنتی نداره؛ همه‌چیز فقط روی خود گوشی ذخیره میشه.
